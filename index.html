사용 안내

DeepL API 키 발급 방법 (무료)

  1. DeepL API 페이지에 접속
  2. "무료로 가입하기" 클릭
  3. 이메일, 비밀번호 입력 후 계정 생성
  4. 신용카드 등록 (무료 플랜은 과금되지 않음)
  5. 계정 페이지에서 API 키 복사
  6. 이 페이지에 붙여넣기

무료 플랜: 월 50만자 (약 100~200 페이지 분량)

API 키 저장 안내

  • API 키는 브라우저에만 저장됩니다 (localStorage)
  • 서버로 전송되지 않아 안전합니다
  • 같은 브라우저에서는 한 번만 입력하면 됩니다
  • 다른 기기/브라우저에서는 다시 입력이 필요합니다
  • 언제든 "API 키 변경"으로 수정/삭제 가능

사용 방법

  1. DeepL API 키 입력 및 저장
  2. 번역할 웹페이지 URL 입력
  3. 원하는 번역 언어 선택
  4. "번역" 버튼 클릭
  5. 원문/번역문 토글로 비교

지원 언어

한국어, 영어, 일본어, 중국어, 독일어, 프랑스어, 스페인어

제한 사항

  • 로그인이 필요한 페이지는 번역 불가
  • JavaScript로만 렌더링되는 페이지는 일부 내용 누락 가능
  • 매우 긴 페이지는 시간이 걸릴 수 있음
